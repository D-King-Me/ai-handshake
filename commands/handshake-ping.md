对本仓库做一次握手自检，只报实测，不猜。

1. 先看钥匙：`keys.json` 有就读，没有也行 —— 环境变量同样算数。缺钥匙不报错，只会标成 `11 隔离`。
2. 握手：
   - 全部：`python hello.py --ping all`
   - 指定几家：`python hello.py --ping deepseek,local`
3. 输出表原样贴回，末尾补两句：可用 n 家、隔离 m 家；隔离的各写一句原因（缺钥匙 / 地址错 / 连不上）。

口径（别自己发明）：

| 位 | 含义 | 处置 |
|---|---|---|
| `01` | 通，且 ≤ 8000ms | 进候选 |
| `10` | 通但慢 | 降级到后面 |
| `00` | 超时 / 429 / 空回复 / 5xx | 只允许再试一次 |
| `11` | 401/403/404、连不上、缺钥匙、缺模型名 | 排除，不要再问 |

- `11` 的那家一次请求都没发出去 —— 别为了“确认一下”去重试，那是把隔离当不确定。
- 自检会往 `日志/握手记录.jsonl` 写一行 JSON；`keys.json` 里没有的东西一律不入日志、不回显。
